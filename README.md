# RM_ISDFoundations
This is my escape room project called..
### Help! I've been kidnapped by EVIL and they're making me do BULLSHIT puzzles!

This is a very non serious speedrunning game with a focus on memory and routing as it's main way of slowing you down, you have a lot of tools to escape, but can you actually remember the codes to the keypads?

## Controls
Movement - WASD<br>
Jump - Space/M1<br>
Sprint - Shift<br>
Crouch - Ctrl<br>
Dash - M2 while in Mid Air<br>
Interact - E<br>
Close Menus - Q<br>
Reset - Hold R<br>
